# Validação do Código

Esta pasta contém os registros (prints) dos resultados obtidos durante a validação do código-fonte da página desenvolvida.

### Ferramentas utilizadas

- [W3C HTML Validator](https://validator.w3.org/) — validação da estrutura HTML.
- [W3C CSS Validator](https://jigsaw.w3.org/css-validator/) — validação das folhas de estilo CSS.
